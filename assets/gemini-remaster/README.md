# Castaway Animated Storybook remaster

Run `./PlayGemini.sh` from the project root.

All sprite, background, panorama and audio files come from the validated user
handoff. PNG pixels and WAV bytes are preserved; SAHD files are derived runtime
caches. See import-manifest.json for source hashes and NOTES.txt for art details.

H: original/remastered art. A: aspect mode. S: original/remastered audio.
M: mute. F: fullscreen. Arrow keys: scenes.
