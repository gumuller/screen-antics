# Modern HD-2D Neo-Retro — third visual style

Run `./PlayHD2D.sh` from the repository root, or `./Play.sh --style hd2d`.
H cycles Original / Remaster / HD-2D; 1/2/3 selects directly. L toggles the
HD-2D lighting/effects. A cycles Auto / Original / 16:9 / 21:9 / 43:18.
S selects original/remastered audio, M mutes, F toggles fullscreen.

This pack is separate from assets/gemini-remaster. All 116 atlases, 10 backgrounds,
30 panoramas and 23 WAVs were imported from the validated user handoff. PNG/WAV
bytes are preserved; unpacked frame rectangles follow the exported manifests.
SAHD .rgba files are derived caches, regenerated by Play.sh.

See import-manifest.json for source hashes, HD2D_REMASTER_SPEC.md for the supplied
art specification, and ../../docs/HD2D.md for the native runtime implementation.
